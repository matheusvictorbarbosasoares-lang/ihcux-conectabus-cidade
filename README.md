# Contexto de Uso

O aplicativo foi pensado para pessoas em movimento, principalmente usuários que estão correndo para não perder ônibus, metrô ou conexões de transporte público.

O foco foi criar uma interface rápida, clara e fácil de usar mesmo em ambientes movimentados e com distrações externas.

---

# Decisões de UX

As informações mais importantes, como tempo de chegada e lotação do veículo, foram destacadas visualmente para facilitar a tomada de decisão rápida do usuário.

Os elementos clicáveis foram projetados em tamanho maior para melhorar a usabilidade em dispositivos móveis.

Também foram utilizadas poucas informações por tela para reduzir a carga cognitiva.

---

# Acessibilidade

O protótipo foi pensado para uso com apenas uma mão, facilitando a navegação para usuários carregando mochilas, bolsas ou sacolas.

Além disso, a tela de detalhes do veículo informa recursos de acessibilidade como:

* Rampas
* Ar-condicionado
* Lotação do veículo

Isso ajuda pessoas com mobilidade reduzida ou em situações de pressa a escolherem a melhor rota.
